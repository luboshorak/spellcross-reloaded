To rebuild from the supplied source, extract SOURCE-CODE.zip into a writable
folder. Install Visual Studio C++ build tools (v145 for the game) and the
compatible x64 wxWidgets/vcpkg dependencies; use the project's original
MSVC configuration. From Developer PowerShell, change to the extracted
source root and run these commands with your own wxWidgets path:

  $wx = "$HOME\vcpkg\installed\x64-windows\"
  msbuild .\spellcross-remaster-main\source\spellcross_map_editor.vcxproj /m /t:Rebuild /p:Configuration=Release /p:Platform=x64 "/p:wxwin=$wx"
  msbuild .\external\map-editor\source\spellcross_map_editor.vcxproj /m /t:Rebuild /p:Configuration=Release /p:Platform=x64 "/p:wxwin=$wx"

To change libsmacker, edit third_party\libsmacker\smacker.c and related
headers before rebuilding the game. To change XMIDI, edit
source\cxxmidi\guts\cvt_xmi2mid.hpp in the respective game/editor source
directory before rebuilding. The source includes the MSBuild inputs and
project support data, not the commercial game data. The player supplies
their own original retail data. See the full project for further docs:
https://github.com/luboshorak/spellcross-reloaded
