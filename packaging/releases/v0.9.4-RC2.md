# Spellcross Reloaded v0.9.4-RC2

Windows x64 release candidate. Changes are relative to v0.9.3-RC1.

## Tactical and campaign fixes

- Destroying Daertor completes the DestroyUnit objective. SaveUnit and TransportUnit still require the target to survive and reach its destination. Death events are queued from both combat and corpse cleanup. (#88)
- Commander assignments shown in the hierarchy are carried into battle. Loading older saves reconciles conflicting assignment records using the displayed host company. The tactical unit panel marks the company carrying the commander. (#85)
- The rescued Commando uses level 6. Legacy Commando XP above the reachable cap is repaired on load. Valid level-12 companies retain their progression. Zero-threshold XP tables no longer advance strategic units to the maximum level, and the HUD handles equal XP thresholds. (#84)
- Background visibility rebuilds no longer produce contact reports from every selected unit. Explicit unit sight updates own the reporting result. (#86)
- Exiting from the strategic map or a paused battle writes a separate Continue save. Restarting and choosing Continue restores the saved campaign or battlefield, including tactical camera position. The save is replaced only after writing succeeds. Finish deployment, close an active message, and let ongoing movement/combat or the enemy turn finish before exiting. (#89)
- The tactical Info button activates an inspection cursor. Click a visible unit to view level, personnel, morale, action points, attack and defence. Escape cancels inspection. (#87)

## Retail language loading and diagnostics

- Polish and Italian retail resources are identified independently of the 206/207-byte unit definition layout. CZ/EN selection keeps its established precedence for mixed archives.
- Polish and Italian mission text uses the corresponding Windows code page and retail font. Italian string tables beginning immediately with a record retain that first record.
- The loader writes and flushes resource names, progress and exceptions to `Spellcross-startup.log` beside the configuration file, with a temporary-directory fallback.
- The Reloaded UI catalogs currently cover Czech and English. Polish and Italian retail loading is experimental and still requires full campaign playtesting.

## Packages and installation

- `Spellcross_Reloaded_v0.9.4-RC2.zip` is the portable Windows x64 package.
- `Spellcross_Reloaded_v0.9.4-RC2.exe` is the WinRAR SFX installer, produced when WinRAR is available.

Extract or install into a writable folder, launch `Spellcross.exe`, and select your original game data when prompted. The package includes the standalone map editor under `Editor`. Keep a backup of existing saves when trying this candidate.

The Windows FileVersion and ProductVersion are `0.9.4.0`. The displayed release label and asset names use `0.9.4-RC2`.

## Validation before publication

Automated source checks cover version/resource consistency, localization catalogs and campaign invariants. Portable C++ regressions cover campaign events, mission flow, countdowns, unit availability, purchase unlocks, RC version ordering and startup-log durability/concurrency.

The candidate still needs a clean Windows Release x64 rebuild, package verification and gameplay checks.

- Load the saves attached to #84, #85 and #88. Verify Commando XP, commander hosts and Daertor mission completion.
- Discover enemies with multiple units and verify contact reports.
- Inspect visible allied/enemy units and cancel inspection with Escape.
- Exit and restart from both strategic and tactical maps, then choose Continue. Verify positions, AP, casualties, objectives, hierarchy and camera. Confirm an in-progress action cannot overwrite the Continue save.
- Load CZ and EN data, then separately exercise PL and IT loading, names, fonts and briefings.
- Exercise chapter transitions, cutscenes, sound, tactical save/load, the editor and both distribution packages on Windows.
