# Spellcross Reloaded v0.9.3 RC1

**Release candidate 1 · Windows x64 · Based on v0.9.2.3**

This release candidate focuses on restoring the original strategic campaign behavior and fixing unit-management problems found during late-campaign playtesting. The underlying tactical AI and battle engine continue the v0.9.2.3 line; later missions have been exercised in gameplay, but this is still a **release candidate**, not a claim that every mission has been exhaustively tested.

## Changes since v0.9.2.3

- **Shared unit availability timer:** newly purchased or battle-returning units remain unavailable for the intended number of turns, and recruitment/rearm/replacement operations cannot bypass the lockout. Engine, weapon and armour upgrades may be ordered together and finish when the **longest common countdown** expires. Older strategic saves with ongoing upgrades are handled. ([#79](https://github.com/luboshorak/spellcross-reloaded/pull/79))
- **Correct campaign unit unlocks:** availability derives from the original `RESEARCH.DEF` entries and scripted `SetResearchFlag` commands across all campaign chapters. Basic units with no research, level or scripted unlock requirements — notably the **Hummer** — are not hidden by a missing flag. Later chapter unlocks remain restricted. ([#79](https://github.com/luboshorak/spellcross-reloaded/pull/79))
- **Accurate strategic countdown graphics:** the map composes original `VM_0`–`VM_9` sprites into numbers such as **10**, **12** and **15**, instead of displaying a misleading **9** for every two-digit countdown. The turn-limit logic is unchanged. ([#80](https://github.com/luboshorak/spellcross-reloaded/pull/80))
- **Clean end-of-chapter transition:** the final victory is recognized before obsolete events from the completed strategic map can raise enemy-attack and reinforcement dialogs. The new chapter's introduction events run after transition videos, preserving legitimate bonuses and attacks. ([#81](https://github.com/luboshorak/spellcross-reloaded/pull/81))
- **Regression coverage:** focused C++ and Python checks cover countdowns, upgrade lockouts, campaign unlock rules and mission-event ordering.

## Installation

Once built and published, choose:

- `Spellcross_Reloaded_v0.9.3-RC1.zip` — portable package; unpack into a writable directory.
- `Spellcross_Reloaded_v0.9.3-RC1.exe` — optional WinRAR SFX with user-selectable installation folder.

Both packages are intended to contain `Spellcross.exe`, the standalone Spellcross map editor, and the verified runtime/video support files. **Original commercial Spellcross game archives are not bundled.** Supply your own Czech or English CD/ISO or existing game data when prompted. On fresh systems, the [Microsoft Visual C++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe) may be required.

The binary Windows FileVersion/ProductVersion is **0.9.3.0**; **v0.9.3-RC1** is the human-readable release identifier. The build packager verifies the compiled EXE version before creating files named for this RC.

## RC1 validation priorities

Before general publication, check a clean Windows 10/11 installation, load an existing save (back up saves first), purchase Hummer, purchase and upgrade units across several turns, confirm `10+` overlays in the desert/late campaign, finish a chapter's final mission without obsolete attack/reinforcement dialogs, and verify chapter-intro videos and legitimate chapter bonuses. Run a tactical mission with sound, AI and save/load. Test the included map editor and both ZIP/SFX distribution forms.
