# Spellcross Reloaded v0.9.4.1

Windows x64 maintenance release. Changes below are relative to the published [v0.9.4-RC2](https://github.com/luboshorak/spellcross-reloaded/releases/tag/v0.9.4-RC2).

## Campaign and saved games

- **Completed story missions stay completed after an OS attack.** Defence and recapture use generated battle state throughout briefing, launch, deadlines and results. Refusing an attack on territory 10 in the desert chapter no longer restores the completed major-rescue mission or its timer and rewards. Existing saves retaining attack/occupation records are recognized. (#97)
- **Mission objectives retain their names after loading.** Objective text is recovered from the original mission definition while the saved targets and completion states are preserved. Existing affected tactical saves are supported. (#94)
- **Temporary companies retain their identity.** Czech support names are converted correctly between original CP895 data and the strategic UTF-8 interface. Both normal and generated battles preserve company names and chapter-support status, including the blue tactical marking. Older battle saves recover missing metadata when matching strategic context and company UIDs are available. (#96)

## Interface and controls

- Strategic Escape uses the normal save-and-return-to-menu path.
- Console input is handled at frame level, and fullscreen transitions restore keyboard focus. Held console keys do not repeatedly reopen the dialog.
- The tactical `SHOWMAP` command toggles full terrain and unit display. Turning it off restores normal visibility without permanently revealing terrain or enemies. The override resets on disk-save or mission load. (#95)
- The strategic wx interface uses the same visual style as the game menu. The shared Help menu includes a keyboard and mouse controls guide.

## Packages

- `Spellcross_Reloaded_v0.9.4.1.zip` — portable game and standalone map editor.
- `Spellcross_Reloaded_v0.9.4.1.exe` — WinRAR SFX installer, when built with WinRAR.
- FileVersion and ProductVersion: **0.9.4.1**.
- Display label: **0.9.4.1**; Git tag: **v0.9.4.1**.

Extract or install into a writable folder and launch `Spellcross.exe`. Keep a backup of saves when updating. The game-data wizard supports Czech and English editions; Polish and Italian retail-data loading remains experimental. Original commercial game archives are not included.

## Validation and release checks

Automated strategy checks cover mission selection, deadlines, script events and version consistency. Native integration regressions cover objective text, temporary company identity and the completed-rescue/recapture lifecycle with original resources.

Before publishing, perform a clean Windows x64 rebuild and package verification. Smoke-test Continue from strategic and tactical saves, defence/recapture, temporary company names and marks, mission objectives, fullscreen/console/ESC, CZ/EN loading, sound, cinematics and the standalone editor. A package must contain all 37 manifest-verified fallback videos and freshly compiled executables.
