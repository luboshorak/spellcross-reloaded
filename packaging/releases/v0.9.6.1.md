# Spellcross Reloaded v0.9.6.1

This maintenance release consolidates the post-v0.9.6 fixes for campaign progression, tactical animations and controls, strategic counterattacks, commanders, and the original cutscene sequence.

**Important:** Back up your saves before updating. Spellcross Reloaded is an unofficial restoration and still requires data from your own original Czech or English Spellcross installation/CD/ISO. Original commercial game files are not redistributed.

## Changes

- **Tactical combat and commands**
  - Continue an already-started mobile-infantry takeoff/landing or MLRS rocket flight when the player selects another unit. Group movement waits for units still completing special actions ([#161](https://github.com/luboshorak/spellcross-reloaded/issues/161), [#164](https://github.com/luboshorak/spellcross-reloaded/issues/164)).
  - Prevent tactical combat, enemy turns and mission events from continuing beneath end-of-level/chapter cinematics ([#162](https://github.com/luboshorak/spellcross-reloaded/issues/162)).
  - Fix the zero-health but still visible/damageable destructible-wall edge case ([#149](https://github.com/luboshorak/spellcross-reloaded/issues/149)).
- **Strategic campaign**
  - Restore randomized Other Side counterattacks based on the original level parameters, including frontier territory selection, force construction and save-state persistence ([#154](https://github.com/luboshorak/spellcross-reloaded/issues/154)).
  - Use the original battlefield's DTA L5 Other Side deployment posts for dynamically generated recapture missions, rather than assuming the enemy always approaches from the north ([#163](https://github.com/luboshorak/spellcross-reloaded/issues/163)).
  - Heal surviving wounded soldiers after a successfully completed battle, including companies earned in the opening mission; dead members still require recruits ([#155](https://github.com/luboshorak/spellcross-reloaded/issues/155)).
  - Restore promotion checks for subordinate officers based on their battle deployments and the original `HODNOSTI.DEF` thresholds ([#148](https://github.com/luboshorak/spellcross-reloaded/issues/148)).
- **Hierarchy and presentation**
  - Keep hierarchy commander labels inside their allotted positions, separate unit/commander labels, and repair missing or duplicate commander IDs when restoring strategic saves ([#156](https://github.com/luboshorak/spellcross-reloaded/issues/156)).
  - Restore distinct tactical markers for chapter-long volunteer units (white), mission-only units (blue), and critical units (red) ([#157](https://github.com/luboshorak/spellcross-reloaded/issues/157)).
  - Make long mission briefings scrollable and remove stray DOS text control characters ([#151](https://github.com/luboshorak/spellcross-reloaded/issues/151), [#152](https://github.com/luboshorak/spellcross-reloaded/issues/152)).
  - Preserve and queue multiple chapter opening/closing videos in the order prescribed by the original `LEVEL_XX.DEF` instead of overwriting earlier commands ([#150](https://github.com/luboshorak/spellcross-reloaded/issues/150)).

## Verification and remaining limitations

Automated CI exercises the original level parser, C++ rules tests, Python integration checks, and compilation of the changed tactical/strategic C++ code under MSVC on Windows. **It is not a full native Windows campaign playthrough.** Original game assets and the reporter's attached saved games are needed to confirm the fixes in real gameplay.

- The exact DOS random-number sequence and targeting preferences for strategic counterattacks have not been fully reverse-engineered. Unit force composition is approximate.
- Chapter movies now preserve script order; the reported long delay before some videos has not been separately diagnosed or eliminated.
- Windows game testing is still recommended for MLRS impacts, mobile-infantry group movement, AI contact in level-8 recaptures, fully populated commander hierarchies and full chapter transitions.
- The reported WinRAR SFX extraction window closing early ([#147](https://github.com/luboshorak/spellcross-reloaded/issues/147)) has **not** been reproduced or changed; the reporter states extraction succeeds and the game starts.

Full reproduction and acceptance checklist: [Desktop regression QA](../../docs/regressions/issues-150-164-desktop-qa.md).

## Installation

Download and extract the complete Windows x64 ZIP (or run the optional SFX installer), then launch `Spellcross.exe`. Existing installations can usually be replaced after backing up saves and settings. Select your own original CZ/EN game data on first launch.
