# Spellcross Reloaded v0.9.5

Windows x64 release candidate. Changes below are relative to [v0.9.4.2](https://github.com/luboshorak/spellcross-reloaded/releases/tag/v0.9.4.2).

## Tactical controls

- Restore familiar **hold right mouse button + drag** camera panning. The two experimental edge-scroll changes (#115, #116) have been rolled back. Right click no longer deselects a group or forces the MOVEMENT MODE range overlay; **Escape** cancels a selected group. (#117)
- Enable **Drag-select unit groups** by default for new game sessions. Its Options check item remains available to turn it off; numbered groups and left-click unit commands are unaffected.
- Harden transition from a temporary group to a single unit: refresh movement and attack ranges after deselection and distinguish a click from a real drag. (#111)
- Recover lost mouse-button-up/focus events in fullscreen without advancing tactical turns under another window. (#113)

## Stability, diagnostics and saves

- Protect object-hit animations from dereferencing a missing hit animation during tactical combat. (#110)
- Record self-contained Windows crash reports (`crash-last.txt`, `crash-last.dmp`, prior crash copies), stack frames and exception context. Include the corresponding `symbols/Spellcross.pdb` and build identity in both ZIP and SFX packages. (#110)
- When a running action cannot be saved, the Exit command offers **Stay in game** or **Exit without saving** instead of repeatedly showing an uncloseable informational message. Old saves are left intact. (#114)

## UI consistency

- Match the dark-green strategic palette in the remaining main-menu and tactical auxiliary dialogs: Audio, Screen, About and Controls help.
- Use owner-drawn green buttons and sliders rather than gray native Windows buttons/trackbars. Screen scaling mode is selected through styled buttons. Preserve volume preview, screen preview and Cancel rollback, keyboard controls and translated text.

## Packages

- `Spellcross_Reloaded_v0.9.5.zip` — portable game and standalone map editor.
- `Spellcross_Reloaded_v0.9.5.exe` — optional WinRAR SFX installer.
- Windows FileVersion / ProductVersion **0.9.5.0**; display/package label **0.9.5**; Git tag **v0.9.5**.

Original commercial game data is not included. CZ/EN are supported; PL/IT remain experimental.

## Validation and release checklist

- CI: Windows C++ compilation, styled menu/control tests, tactical selection input tests, release metadata and existing campaign regressions.
- Manual Windows smoke test before publishing: CZ/EN loader; main, tactical and strategic menu/help dialogs; Audio/Screen preview and Cancel; About/update check; native fullscreen and Alt+Enter; RMB camera dragging; LMB box selection on by default and switchable off; Escape group cancel; campaign transitions, Save/Continue, cinematics and crash report presence.
- Rebuild on the final reviewed source using `packaging/Build-CombinedRelease.ps1 -Rebuild` and publish the tested artifacts yourself. No distributable binaries are created by this source-only preparation.
